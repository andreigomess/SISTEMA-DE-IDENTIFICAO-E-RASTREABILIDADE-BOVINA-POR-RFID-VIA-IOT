# SISTEMA-DE-IDENTIFICA-O-E-RASTREABILIDADE-BOVINA-POR-RFID-VIA-IOT
Projeto de iniciação científica. Aqui, vamos versionar todo o projeto, desde a parte de coleta de dados com RFID até o sistema web completo com o banco de dados e a visualização dos dados de cada animal, juntamente ao seu rastreio.

Organização:
- /Aplicação Backend: backend da aplicação web para visualização dos dados.
- /Aplicação Frontend: frontend da aplicação web.
- /Hardware: toda a parte de programação do microcontrolador Esp32.
